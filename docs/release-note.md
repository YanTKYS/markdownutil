# リリースノート

バージョンごとの変更点を新しい順に記載します。現在の機能・利用方法はREADMEと`docs/`配下、
テスト手順は[`docs/TESTING.md`](TESTING.md)を参照してください。

## v0.7.2

- README・`docs/`配下・ソースコードコメントを、現行仕様の理解に必要な内容へ整理
- 各リリースの手動テストログを積み上げていた`docs/TESTING.md`を、実行手順と確認項目を
  まとめたテスト手順書へ置き換え
- 機能コードの動作変更はなし

## v0.7.1

- README.mdを、概要・主な機能・使い方・対応形式・同梱ライブラリ・配置の要点と
  詳細ドキュメントへのリンクだけを載せる構成へ再編。形式・スライド・Word出力ごとの
  詳細仕様は`docs/`配下へ分離
- `vendor/manifest.json`を新設し、同梱ライブラリ（AnyDoc WASM / markdown-it / Marp Core /
  docx）のバージョンの正本とした。README・`LICENSES/THIRD_PARTY_NOTICES.md`・各vendor配下との
  整合性を検証するテストを追加
- 依存ライブラリの更新手順を`docs/dependencies.md`へ文書化

## v0.7.0

- 同梱する`@firecrawl/anydoc-wasm`を0.1.8から0.2.3へ更新（`js/converter.js`はAPI互換のため
  変更なし）
- `.docx` / `.pptx` / OpenDocument / `.rtf` / `.epub`の数式がLaTeX記法で出力されるようになった
- 表計算のフォームコントロールのチェックボックスが`[x]` / `[ ]`として出力されるようになった
- 表計算のセル表示形式（通貨・パーセント・桁区切り）が変換結果へ反映されるようになった
- `.xlsb`が変換できるようになった（0.1.8では`malformed`になっていた）

## v0.6.9

- プレゼン中に発表者ビューをクリックすると、以降キーボードでページを送れなくなる不具合を修正
  （フォーカスがiframeへ移った後の転送キー操作を本体が引き取っていなかった）
- ページ送りのたびに全描画先へスライド全体を送り直していたため、枚数の多い資料でページ送りが
  遅く・ちらついていた問題を修正。内容の流し込みは発表開始時の1回だけにした
- 本文が空のまま「HTML出力」「印刷」「プレゼン表示」を実行できてしまう不具合を修正
  （Marpは空でも白紙1枚を描画するため、枚数だけでは中身の有無を判断できなかった）

## v0.6.8

- 文書モードのプレビューで、Marpのfront matterが見出しとして表示され、HTMLコメントが
  そのまま本文へ出ていた不具合を修正（Word出力と同じ前処理を共有するようにした）
- Word出力で、`3.`のように途中の番号から始まる番号付きリストが1から振り直されていた不具合を修正
- Word出力で、表の`| ---: |`（桁揃え）が無視されていた不具合を修正

## v0.6.7

- Word出力で、Marpのfront matterが本文へ印字されることがある不具合を修正
  （`---`の後ろに空白がある場合、ディレクティブの間に空行がある場合）
- スライドの描画自体に失敗しているとき、「少し待ってから再度お試しください」ではなく
  失敗の原因を表示するよう修正

## v0.6.6

- 左右ペインのヘッダ高さ・padding・vertical alignmentを共通ルールへ統一し、
  ヘッダと本文開始位置のずれを解消
- Markdown編集欄のフォントを等幅から日本語文書編集向けのゴシック体へ変更し、
  font-size・line-heightを調整
- スライド専用ツールバーをペインヘッダの外へ移動し、中間幅（860px超〜1200px弱）で
  右ヘッダだけ折り返してずれる問題を修正

## v0.6.5

- READMEを現行仕様中心の構成へ整理し、積み上がっていたv0.1.0〜v0.6.4の履歴を
  リリースノートへ分離

## v0.6.4

- Devinチームが並行して作成した3件のPull Request（共通処理の整理・postMessage/CSPの
  セキュリティ強化・ユニットテスト基盤）を、v0.6.3の土台へ統合
- `js/dom.js` / `js/download.js` / `js/inline-html.js`へ機能非依存の重複処理を切り出し
- iframe/別ウィンドウ間の`postMessage`に送信元window・オリジンの検証を追加
- CSP（Content-Security-Policy）を設定
- Node.js組み込みのテストランナー（`node --test`、追加の依存パッケージなし）による
  ユニットテストを導入

新機能の追加は行わず、既存v0.6.xの品質・安全性・保守性・テスト容易性を向上させたリリースです。

## v0.6.3

- エラーの通知と原因の記録を見直し
- 失敗しているのに成功したように見える経路（HTMLの組み立てに失敗しても「保存しました」と
  表示していた等）と、失敗が画面に出ないまま止まる経路をふさいだ
- 利用者へは短い日本語メッセージ、原因となった例外はブラウザの開発者ツール（console）へ
  `[MarkdownUtil]`接頭辞付きで記録するよう変更（外部への送信は行わない）

## v0.6.2

- Word出力の表示上の不具合を2件修正
- 表の列幅が本文幅で等分されるよう修正
- 1つのリスト項目に補足の段落を続けた場合に、別の項目として出力されないよう修正

## v0.6.1

- Word出力中（生成に時間がかかる長文の場合）に別のファイルを開くと、出力される内容と
  ファイル名がずれる可能性があった不具合を修正
- 「Word出力」を押した時点のMarkdownとファイル名をスナップショットしてから生成するよう変更

## v0.6.0

- 上部ツールバーに「Word出力」を追加
- 現在のMarkdownを、サーバやMicrosoft Wordを使わずブラウザ内だけでMicrosoft Word形式

## v0.5.1

  消えてしまう不具合を修正

## v0.5.0

  試せるチュートリアルを実装（編集中のMarkdownがある場合は上書き確認）

## v0.4.2

- ヘルプに「使い方」「プレゼン」タブを追加
- MarkdownUtil自体の利用方法（変換・編集・表示・保存の流れ）を画面内で確認可能に

## v0.4.0

- Markdown編集領域に「? ヘルプ」ボタンを追加
- Markdown / Marpの代表的な記法をタブ切替形式の早見表で確認でき、各記法例はそのまま

## v0.3.0

- スライド機能を実際の会議・説明で使えるよう拡張
- 「プレゼン表示」をMarkdownUtil自身の全画面化から、投影用の別ウィンドウを開く方式へ変更
- 手元のMarkdownUtilは発表者ビュー（現在のスライド・次のスライド・スピーカーノート・
  現在位置・前後操作）として利用可能に
- 庁内IISがHTTP配信であることを前提に、拡張ディスプレイへの自動検出・自動配置は行わない方針
- HTML出力を縦一覧表示から、単体で開いてそのままスライドショーできる形式へ変更

## v0.2.0

- 右ペインのプレビューに、通常のMarkdown表示（文書モード）に加えて
  [Marp Core](https://github.com/marp-team/marp-core) によるスライドプレビュー
  （スライドモード）を追加
- 同じMarkdownを、通常の文書としても、Marp記法によるスライドとしても確認可能に

## v0.1.0

- 文書変換エンジン [AnyDoc](https://github.com/firecrawl/anydoc) のWebAssembly版
  （`@firecrawl/anydoc-wasm`）が実際の業務文書で実用に耐えるかを検証することを主目的とした
  試験版
- 「開く → 変換 → 編集 → プレビュー → コピー／保存」まで一連の操作ができる状態を実装
