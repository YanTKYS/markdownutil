# リリースノート

## 運用方針

- バージョンごとの変更履歴はこのファイルへ追記する。
- README.mdは現在の機能・利用方法を記載し、原則としてリリース履歴を追加しない。
- 詳細な検証記録はdocs/TESTING.mdへ記載する。

## v0.6.6

- 左右ペインのヘッダ（`MARKDOWN` / `プレビュー 文書 スライド`）の高さ・padding・vertical
  alignmentを共通の`.pane-header`ルールへ統一し、左右で見比べたときのずれを解消
- ヘッダ直下のMarkdown編集欄・プレビュー本文の開始位置がヘッダ高さの統一により自然に揃うよう修正
- Markdown編集欄のフォントを、等幅フォント（`--font-mono`）から日本語文書編集向けの
  `"BIZ UDPGothic", "Yu Gothic UI", "Yu Gothic", Meiryo, sans-serif`へ変更
- Markdown編集欄のfont-size（13.5px→14px）・line-height（1.6→1.7）を、フォント変更後の
  可読性に合わせて小さく調整
- 860px以下の上下配置レスポンシブ表示は維持（左右ペインヘッダの高さ統一はこの表示でも適用）
- スライド専用ツールバー（テーマ選択・HTML出力・印刷・プレゼン表示）を`.pane-header`の
  外（独立した行）へ移動。2ペイン表示を維持する中間幅（860px超〜1200px弱）でスライド
  モード時に右ヘッダだけ折り返して左とずれる問題を修正（PRレビュー指摘への対応）

AnyDoc変換・保存・コピー・Word出力・文書プレビュー・Marp処理・HTML出力・印刷・プレゼン表示・
発表者ビュー・ヘルプ・サンプル・CSP・postMessage・エラー処理・テスト基盤等の機能コードは
変更していません。CSS中心の修正です（`index.html`はスライド専用ツールバーの位置移動のみ）。

## v0.6.5

- READMEを「現在のMarkdownUtilの仕様・利用方法」を中心とする構成へ整理
- READMEに積み上がっていたv0.1.0〜v0.6.4の履歴をリリースノートへ分離
- README内のバージョン依存表現・重複説明を整理
- README / release-note / TESTINGの役割を明確化

機能変更はありません。

## v0.6.4

- Devinチームが並行して作成した3件のPull Request（共通処理の整理・postMessage/CSPの
  セキュリティ強化・ユニットテスト基盤）を、v0.6.3の土台へ統合
- `js/dom.js` / `js/download.js` / `js/inline-html.js`へ機能非依存の重複処理を切り出し
- iframe/別ウィンドウ間の`postMessage`に送信元window・オリジンの検証を追加
- CSP（Content-Security-Policy）を設定
- Node.js組み込みのテストランナー（`node --test`、追加の依存パッケージなし）による
  ユニットテストを導入

新機能の追加は行わず、既存v0.6.xの品質・安全性・保守性・テスト容易性を向上させたリリースです。

## v0.6.3

- エラーの通知と原因の記録を見直し
- 失敗しているのに成功したように見える経路（HTMLの組み立てに失敗しても「保存しました」と
  表示していた等）と、失敗が画面に出ないまま止まる経路をふさいだ
- 利用者へは短い日本語メッセージ、原因となった例外はブラウザの開発者ツール（console）へ
  `[MarkdownUtil]`接頭辞付きで記録するよう変更（外部への送信は行わない）

## v0.6.2

- Word出力の表示上の不具合を2件修正
- 表の列幅が本文幅で等分されるよう修正
- 1つのリスト項目に補足の段落を続けた場合に、別の項目として出力されないよう修正

## v0.6.1

- Word出力中（生成に時間がかかる長文の場合）に別のファイルを開くと、出力される内容と
  ファイル名がずれる可能性があった不具合を修正
- 「Word出力」を押した時点のMarkdownとファイル名をスナップショットしてから生成するよう変更

## v0.6.0

- 上部ツールバーに「Word出力」を追加
- 現在のMarkdownを、サーバやMicrosoft Wordを使わずブラウザ内だけでMicrosoft Word形式
  （`.docx`）へ変換し、そのまま保存可能に

## v0.5.1

- Office/PDF変換中にサンプルを挿入すると、変換完了時のMarkdown上書きと競合して挿入内容が
  消えてしまう不具合を修正
- 変換中はサンプル挿入のみを案内メッセージ付きで止め、ヘルプ自体は引き続き変換中も開閉可能に

## v0.5.0

- 「使い方」タブに「文書サンプル」「スライドサンプル」を追加
- 実際のMarkdownをエディタへ挿入し、編集しながらMarkdownUtilの「文書」「スライド」機能を
  試せるチュートリアルを実装（編集中のMarkdownがある場合は上書き確認）

## v0.4.2

- ヘルプに「使い方」「プレゼン」タブを追加
- MarkdownUtil自体の利用方法（変換・編集・表示・保存の流れ）を画面内で確認可能に

## v0.4.0

- Markdown編集領域に「? ヘルプ」ボタンを追加
- Markdown / Marpの代表的な記法をタブ切替形式の早見表で確認でき、各記法例はそのまま

## v0.3.0

- スライド機能を実際の会議・説明で使えるよう拡張
- 「プレゼン表示」をMarkdownUtil自身の全画面化から、投影用の別ウィンドウを開く方式へ変更
- 手元のMarkdownUtilは発表者ビュー（現在のスライド・次のスライド・スピーカーノート・
  現在位置・前後操作）として利用可能に
- 庁内IISがHTTP配信であることを前提に、拡張ディスプレイへの自動検出・自動配置は行わない方針
- HTML出力を縦一覧表示から、単体で開いてそのままスライドショーできる形式へ変更

## v0.2.0

- 右ペインのプレビューに、通常のMarkdown表示（文書モード）に加えて
  [Marp Core](https://github.com/marp-team/marp-core) によるスライドプレビュー
  （スライドモード）を追加
- 同じMarkdownを、通常の文書としても、Marp記法によるスライドとしても確認可能に

## v0.1.0

- 文書変換エンジン [AnyDoc](https://github.com/firecrawl/anydoc) のWebAssembly版
  （`@firecrawl/anydoc-wasm`）が実際の業務文書で実用に耐えるかを検証することを主目的とした
  試験版
- 「開く → 変換 → 編集 → プレビュー → コピー／保存」まで一連の操作ができる状態を実装
